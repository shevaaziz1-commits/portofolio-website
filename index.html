Tentang Saya

Halo, perkenalkan nama saya Sheva Aziz. Saat ini saya merupakan mahasiswa Universitas Islam Negeri (UIN) Syarif Hidayatullah Jakarta, Fakultas Sains dan Teknologi, Program Studi Sistem Informasi. Saya memiliki ketertarikan terhadap perkembangan teknologi informasi, khususnya dalam bidang Web Development, pemrograman, dan pengembangan sistem informasi. Sebagai mahasiswa Sistem Informasi, saya ingin memahami bagaimana teknologi dapat dimanfaatkan untuk membantu menyelesaikan berbagai permasalahan serta mendukung kebutuhan manusia dalam kehidupan sehari-hari. Saat ini saya sedang mempelajari dasar-dasar pengembangan website menggunakan HTML dan terus berusaha meningkatkan kemampuan saya dalam bidang teknologi. Saya juga tertarik untuk mempelajari berbagai hal baru yang berkaitan dengan dunia digital dan perkembangan teknologi informasi. Selain itu, saya senang bekerja sama dalam tim, bertukar ide, serta mendapatkan pengalaman dan pengetahuan baru. Saya percaya bahwa kemampuan komunikasi, kreativitas, tanggung jawab, dan kemauan untuk terus belajar merupakan hal penting dalam proses pengembangan diri. Melalui website portofolio ini, saya ingin memperkenalkan diri, menampilkan kemampuan yang sedang saya kembangkan, serta mendokumentasikan perjalanan dan proses belajar saya sebagai mahasiswa Sistem Informasi. Saya berharap dapat terus berkembang dan menghasilkan karya yang bermanfaat di bidang teknologi informasi.
